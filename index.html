.xlsx, .xls, .csv — ek saath kai files (Amazon MTR, Flipkart Sales Report, Meesho tcs_sales / tcs_sales_return, other platforms template)

Report kahan se download karein?
  • Amazon: Seller Central → Reports → Tax Document Library → MTR (Merchant Tax Report) — B2C aur B2B dono download karke (zip ho to extract karke) CSV daaliye.
  • Flipkart: Seller Hub → Reports → Tax Reports → Sales Report / GSTR report (month select kijiye) — poori Excel file daaliye, tool "Sales Report" sheet khud padh lega.
  • Meesho: Supplier Panel → Payments → Download GST Report → zip extract karke tcs_sales.xlsx aur tcs_sales_return.xlsx dono daaliye.
  • Baaki platforms / apni website / offline: Template download kijiye, usme data bhar ke upload kijiye. platform column mein naam (jaise JioMart, Myntra) likhiye; apni website ke liye khali chhodiye.
  • Demo ke liye repo ke sample-data/ folder ki files try kijiye (GSTIN 27AAPFU0939F1ZV, October 2025).

5 GST portal par upload kaise karein

  1. gst.gov.in par login → Services → Returns → Returns Dashboard → financial year aur month chuniye → Search.
  2. GSTR-1 tile mein Prepare Offline → Upload tab → Choose File → is tool ki JSON file chuniye.
  3. Status "Processed" hone tak wait kijiye (kuch minute). Error aaye to Generate error report se dekhiye.
  4. Wapas Prepare Online → tables check kijiye → Generate GSTR-1 Summary → File Statement with DSC/EVC.
  5. GSTR-1 file hone ke baad GSTR-3B ka Table 3.1 aur 3.2 apne aap bhar jaata hai — tool ke GSTR-3B tab se milaan kar lijiye.

⚠️ Ye tool aapki madad ke liye hai — file karne se pehle numbers ek baar zaroor check kijiye (ya CA se karwaiye).
